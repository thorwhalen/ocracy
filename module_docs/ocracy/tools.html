ocracy.tools

Command-line tools for ocracy (dispatched via argh in __main__).

Each function here is a thin, CLI-friendly wrapper over the Python API; argh turns their signatures into subcommands and options. Run ocracy <command> --help (after pip install 'ocracy[cli]') or python -m ocracy <command>.

ocracy.tools.backends(*, capability: str | None = None)[source]

List the backends ocracy can run right now (optionally by capability).

Parameters:

capability – Filter to a capability, e.g. math, tables, handwriting.

ocracy.tools.find(*, local: bool = False, remote: bool = False, free: bool = False, implemented: bool = False, handwriting: bool = False, math: bool = False, tables: bool = False, language: str | None = None)[source]

Filter the ledger and print matching backends (id, where, pricing, best-for).

Flags compose (AND). Example: ocracy find --local --free --handwriting.

Parameters:

  • local – Keep only backends that run locally.

  • remote – Keep only hosted/remote backends.

  • free – Keep only free / open-source backends.

  • implemented – Keep only backends ocracy can run today.

  • handwriting – Keep only backends that read handwriting.

  • math – Keep only backends that read math/formulas.

  • tables – Keep only backends that extract tables.

  • language – Keep only backends whose languages mention this name/code.

ocracy.tools.info(backend_id: str)[source]

Print a backend’s full ledger record as JSON.

Parameters:

backend_id – A ledger id, e.g. google-vision (see ocracy find).

ocracy.tools.read(image: str, *, backend: str | None = None, languages: str | None = None, output: str = 'text')[source]

OCR an image and print the result.

Parameters:

  • image – Path or http(s) URL to the image.

  • backend – Backend id (default: first installed). See ocracy backends.

  • languages – Comma-separated language codes, e.g. en,fr.

  • output – text (default), json (text + blocks), or markdown.

ocracy.tools.scaffold(backend_id: str, *, dest: str | None = None)[source]

Generate a new backend package from its ledger entry.

Parameters:

  • backend_id – The ledger id to scaffold (e.g. surya).

  • dest – Optional destination directory.

ocracy.tools.validate(backend_id: str)[source]

Smoke-test a backend adapter end to end and print the report.

Parameters:

backend_id – The backend id to validate (e.g. tesseract).
