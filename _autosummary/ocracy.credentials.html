ocracy.credentials#

Credential resolution for remote OCR backends.

Remote engines need an API key (or a path to a service-account JSON). Rather than make each adapter reinvent the lookup, this module centralizes a small, layered resolver:

  1. an explicit value passed by the caller (api_key=...),

  2. the backend’s declared environment variable(s),

  3. (soft) a .env file discovered via python-dotenv if it is installed,

  4. (optional) an interactive prompt, only in a REPL and only if asked.

A backend declares its variable(s) in BACKEND_CONFIG['api_env_var'] (a string or list). The well-known providers below give friendly defaults. The design follows the credential pattern used by the sibling aix facade.

ocracy.credentials.resolve_credential(provider=None, *, api_key=None, env_var=None, required=True, prompt_if_missing=False)[source]#

Resolve a credential for a remote backend.

Parameters:

  • provider (Optional[str]) – A known provider id (see PROVIDER_ENV_VARS) used to infer default env-var names.

  • api_key (Optional[str]) – An explicit value; if given, it wins and is returned as-is.

  • env_var (Union[str, Sequence[str], None]) – Extra env-var name(s) to check (checked before provider defaults).

  • required (bool) – If True (default), raise MissingCredentialError when nothing resolves; if False, return None.

  • prompt_if_missing (bool) – If True and running interactively, prompt the user (via getpass) as a last resort.

Return type:

Optional[str]

Returns:

The resolved secret, or None when required=False and nothing was found.
