# ocracy.backends.tesseract

Tesseract backend for ocracy (via pytesseract).

The canonical local, free, offline OCR engine. Requires the system `tesseract`
binary plus the `pytesseract` Python wrapper.

### Modules

| [`adapter`](ocracy.backends.tesseract.adapter.html.md#module-ocracy.backends.tesseract.adapter)   | Adapter for Tesseract — image -> text+word-boxes via pytesseract.   |
|-----------------------------------------------------------------------------------------------------|---------------------------------------------------------------------|
| [`config`](ocracy.backends.tesseract.config.html.md#module-ocracy.backends.tesseract.config)     | Configuration for the Tesseract backend.                            |
